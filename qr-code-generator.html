QR Code Generator

Generate custom QR codes for text, URLs, Wi-Fi credentials, contact info, and more. Download as PNG. Client-side, secure, and fast.

QR code preview will appear here
QR codes generated locally in your browser. No data is sent to any server. Supports text, URLs, contact (vCard), Wi-Fi, and more.

📖 How to Use

  • Enter any text, URL, or structured data in the input field.
  • Select the desired QR code size (pixels).
  • Click "Generate QR Code" to create the QR code.
  • Click "Download as PNG" to save the QR code image to your device.
  • Use "Reset to Default" to restore the example URL.

⚙️ What Can You Encode?

  • Website URLs: https://example.com
  • Plain text: Any message
  • Contact (vCard): BEGIN:VCARD...END:VCARD
  • Wi-Fi credentials: WIFI:S:SSID;T:WPA;P:password;;
  • Email/Phone/SMS: mailto:email@example.com, tel:1234567890

📱 QR Code Use Cases

  • Share website links, app downloads, or social media profiles.
  • Add contactless menus, payment links, or event check-ins.
  • Encode Wi-Fi credentials for easy network sharing.
  • Create business cards with vCard QR codes.
