Percentage Increase Calculator

Calculate percentage increase or decrease between two values. Also find the new value after adding a percentage, or find the original value before a percentage change.

📊 Percentage Change—
📈 Amount of Change—
Enter values and click Calculate.
📈 New Value—
Enter original value and percentage change.
📉 Original Value—
Enter new value and percentage change.

📖 How to Use

  • Percent Change: Enter old and new values to calculate the percentage increase or decrease.
  • Find New Value: Enter original value and percentage (positive for increase, negative for decrease).
  • Find Original Value: Enter new value and percentage to reverse-calculate the original.

Formula: % Change = (New - Old) / Old × 100. A positive result = increase, negative = decrease.

⚙️ Examples

  • Old = 100, New = 120 → 20% increase
  • Old = 100, New = 80 → -20% decrease
  • Original = 100, increase 20% → New = 120
  • New = 120, increase 20% → Original = 100
