📖 How to Use the GPA Calculator

Add each course with its credit hours and grade. For letter grades, select from A+ (4.0) to F (0.0). For percentage, enter your score (0-100). The calculator converts percentages to GPA using standard 4.0 scale: 90-100% = 4.0, 80-89% = 3.0, 70-79% = 2.0, 60-69% = 1.0, below 60% = 0.0 (or custom). Our calculator uses a standard 10-point scale for percentage conversion.

⚙️ Letter Grade to GPA Conversion

  • A+ / A = 4.0
  • A- = 3.7
  • B+ = 3.3, B = 3.0, B- = 2.7
  • C+ = 2.3, C = 2.0, C- = 1.7
  • D+ = 1.3, D = 1.0, D- = 0.7
  • F = 0.0

📐 GPA Formula

GPA = (Sum of Grade Points × Credit Hours) ÷ (Sum of Credit Hours). Grade points are based on the letter grade or percentage conversion.
