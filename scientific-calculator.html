📖 Scientific Calculator Features

This calculator supports basic arithmetic (+, -, ×, ÷) and advanced functions including:
Trigonometry: sin, cos, tan, asin, acos, atan (degree/radian mode)
Logarithms: log (base 10), ln (natural), exponent (e^x), power (x^y), square root, cube root, nth root
Other: factorial (n!), percentage, constants π and e, parentheses, memory storage.

⚙️ How to Use

Click buttons or use keyboard (numbers, operators, Enter for equals, Backspace to delete). Use DEG/RAD toggle for trigonometric functions. Memory buttons store/recall values. For power (x^y), enter base, press "^", then exponent.

📐 Common Operations

  • sin(30°)=0.5 (in DEG mode)
  • ln(20)=~2.9957
  • 5! = 120
  • √144 = 12
  • π = 3.14159...
