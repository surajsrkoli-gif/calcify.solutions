Privacy Policy

📅 Last updated: April 18, 2026

1. Our Commitment to Privacy

At calcify.solutions, your privacy isn't an afterthought — it's the foundation of how we built this platform. We believe that you shouldn't have to trade your personal data for access to useful tools. That's why we designed every calculator to run entirely in your browser. No accounts, no logins, no data harvesting, no surprises.

🔒 Core promise: We do not collect, store, or sell any personal information. All calculations happen locally on your device. You can even use most calculators offline after the first load.

2. What Data We DO NOT Collect

  • Personal identifiers: Name, email, phone number, address — never requested, never stored.
  • Financial data: Loan amounts, investment figures, tax details — all stay in your browser.
  • Health metrics: Weight, height, age, body measurements — processed locally, not transmitted.
  • IP addresses or browsing history: We don't run analytics scripts that track you across sessions.

When you use a calculator, the numbers you enter never leave your device. Not to our servers, not to third parties. We designed it that way.

3. Cookies & Tracking Technologies

We do NOT use any tracking cookies, advertising cookies, or persistent identifiers. The only exception is technically necessary session storage (e.g., remembering which category you're viewing) — this data stays in your browser and is deleted when you close the tab. We don't use Google Analytics, Facebook Pixel, or any similar tracking service.

If we ever introduce non‑intrusive ads (to keep the site free), they will be served by ad networks that may use cookies. In that case, we will clearly update this policy and provide opt‑out options. As of now, there are no third‑party ads.

4. External APIs & Third‑Party Services

calcify.solutions uses the following external services only for specific features. No personal data is ever sent to these APIs — only the currency code you select (e.g., "USD") and anonymous requests.

  • Frankfurter API (currency conversion): Fetches live exchange rates from the European Central Bank. No API key is required, and no user data is transmitted beyond the requested currency pair.
  • CurrencyAPI (backup currency converter): Uses a public API key. Only the currency codes you choose are sent.
  • GitHub Pages hosting: The website is hosted on GitHub Pages. GitHub may collect standard server logs (IP address, request time) as per their privacy policy, but we have no access to or control over those logs.

No social media logins, no embedded videos, no external fonts that track you. Everything is self‑hosted or uses privacy‑respecting CDNs.

5. Children's Privacy

Our calculators are designed for general audiences and are safe for children (e.g., BMI calculator, age calculator). We do not knowingly collect any information from children under 13. If you believe your child has entered personal information into any of our tools, please note that the data never leaves their device, so there is no stored record for us to delete.

6. Data Security

Since we don't collect any data, there is nothing to steal, leak, or hack. All code is served over HTTPS, and your browser’s local storage is never used for personal information. The only “security” risk would be if the website itself were compromised — in that case, the attacker could only modify the calculator output, not access any of your personal data (because there is none).

7. Your Rights (GDPR, CCPA, etc.)

Because we collect zero personal data, there is no data to access, rectify, delete, or port. You are automatically in full control. If you are concerned about any residual logs (like GitHub Pages server logs), please review GitHub's privacy policy. We do not have access to those logs and cannot identify individual users from them.

8. Changes to This Privacy Policy

Any future changes will be posted on this page with an updated "Last updated" date. If we ever introduce new features that involve data collection (e.g., optional user accounts), we will ask for explicit consent and update this policy prominently. You can always find the latest version at calcify.solutions/privacy.html.

9. Contact Us

If you have any questions about this privacy policy or our practices, you can reach us at:

📧 support@calcify.solutions

Or via our contact page. We aim to respond within 48 hours.

📢 Summary for the privacy‑conscious: This website does not track you, does not store your data, and runs all calculations locally. You can verify this by opening your browser's developer tools — no network requests are made when you use a calculator (except currency converter, which only fetches exchange rates). We built calcify.solutions the way we wish every tool website worked.
