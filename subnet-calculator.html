Note: /31 and /32 subnets have special rules (usable hosts = 0 for /32, 2 for /31). This calculator follows RFC 3021 for point-to-point links.

📖 How to Use

  • Enter an IPv4 address (e.g., 192.168.1.1).
  • Choose either CIDR prefix (e.g., /24) or subnet mask (e.g., 255.255.255.0).
  • Click "Calculate Subnet" to see network details.
  • Use "Reset" to restore default example.

⚙️ Understanding Results

  • Network Address: First address of the subnet (not assignable).
  • Broadcast Address: Last address of the subnet (not assignable).
  • Usable Hosts: Network and broadcast addresses excluded. For /31, 2 usable hosts (RFC 3021). For /32, 0 usable hosts.
  • Wildcard Mask: Inverse of subnet mask, used in access control lists.
  • IP Class: Class A (1-126), B (128-191), C (192-223).

📐 Example

IP: 192.168.1.1, CIDR /24 → Network: 192.168.1.0, Broadcast: 192.168.1.255, Usable: 192.168.1.1 – 192.168.1.254, 254 usable hosts.
