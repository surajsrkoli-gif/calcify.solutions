📖 How to Use the Algebra Calculator

Linear Equation: Enter values for a, b, c in the equation ax + b = c. The calculator solves for x and shows step-by-step work.

Quadratic Equation: Enter a, b, c for ax² + bx + c = 0. The calculator computes the discriminant and roots (real or complex).

⚙️ Solving Methods

  • Linear: Isolate x by subtracting b from both sides, then divide by a.
  • Quadratic: Quadratic formula x = [-b ± √(b² - 4ac)] / (2a). Handles real and complex roots.

📐 Examples

  • 2x + 3 = 7 → x = 2
  • x² - 3x + 2 = 0 → x = 1, x = 2
  • x² + 1 = 0 → x = i, x = -i (complex)
